Política de Privacidade — Achronia Studio

Última atualização: 2 de outubro de 2026

1. O que é o Achronia Studio

O Achronia Studio é uma ferramenta de automação de uso pessoal e privado, operada exclusivamente pelo responsável pelo canal Achronia no YouTube. Ele não é oferecido ao público e não possui usuários além do próprio operador.

2. Uso dos YouTube API Services

O Achronia Studio usa os YouTube API Services. Ao usar o Achronia Studio, você concorda com os Termos de Serviço do YouTube. Os dados acessados por meio dessas APIs também estão sujeitos à Política de Privacidade do Google.

3. Dados do canal, com autorização

Somente com a autorização do próprio dono do canal, via OAuth, o Achronia Studio acessa a conta do YouTube do canal Achronia para:

  • enviar vídeos e definir títulos, descrições, tags, thumbnails, legendas e playlists;
  • ler metadados e estatísticas (YouTube Analytics) do próprio canal, para planejar conteúdo.

4. Pesquisa de pautas, com dados públicos

Para escolher os próximos episódios, o Achronia Studio consulta vídeos públicos do YouTube sobre ferramentas de IA: título, nome do canal, número de visualizações, data de publicação e ID do vídeo. Essa consulta usa uma chave de API, sem OAuth, e não acessa dados privados de ninguém.

  • Esses dados ficam apenas no computador do operador e são atualizados ou apagados em até 30 dias.
  • As notas de pauta calculadas a partir deles são estimativas próprias do Achronia, não dados do YouTube, e são usadas só internamente.

O Achronia Studio não coleta dados privados de outros usuários do YouTube ou do Google.

5. Armazenamento e compartilhamento

  • Os tokens de autorização e todos os dados obtidos pela API ficam apenas localmente, no computador do operador.
  • Nenhum dado é vendido, compartilhado ou transferido a terceiros, nem usado para publicidade.
  • As estatísticas do próprio canal ficam guardadas enquanto a autorização estiver ativa. A ferramenta confere a autorização pelo menos a cada 30 dias e apaga esses dados se ela tiver sido revogada.

6. Como revogar o acesso e pedir a exclusão dos dados

O acesso pode ser revogado a qualquer momento nas configurações de segurança da Conta do Google. Após a revogação, os tokens locais deixam de funcionar e são excluídos.

Para pedir a exclusão dos dados, use o contato da seção 8. Os pedidos são atendidos em até 7 dias.

7. Cookies

Este site não usa cookies nem ferramentas de rastreamento.

8. Alterações e contato

Esta política pode ser atualizada; a data no topo indica a versão vigente. Dúvidas, reclamações e pedidos de exclusão podem ser enviados abrindo uma issue neste repositório.

Privacy Policy — Achronia Studio

Last updated: October 2, 2026

1. What Achronia Studio is

Achronia Studio is a personal, private automation tool operated solely by the owner of the Achronia YouTube channel. It is not offered to the public and has no users other than its operator.

2. Use of YouTube API Services

Achronia Studio uses the YouTube API Services. By using Achronia Studio, you agree to be bound by the YouTube Terms of Service. Data accessed through these APIs is also subject to the Google Privacy Policy.

3. Channel data, with authorization

Only with the channel owner's own OAuth authorization, Achronia Studio accesses the Achronia channel's YouTube account to:

  • upload videos and set titles, descriptions, tags, thumbnails, captions and playlists;
  • read metadata and analytics (YouTube Analytics) of the channel itself, for content planning.

4. Topic research, with public data

To choose the next episodes, Achronia Studio looks up public YouTube videos about AI tools: title, channel name, view count, publish date and video ID. This lookup uses an API key, no OAuth, and accesses no one's private data.

  • This data stays only on the operator's computer and is refreshed or deleted within 30 days.
  • Topic scores calculated from it are Achronia's own estimates, not YouTube data, and are used internally only.

Achronia Studio does not collect private data from any other YouTube or Google users.

5. Storage and sharing

  • Authorization tokens and all data obtained through the API are stored locally only, on the operator's computer.
  • No data is sold, shared or transferred to third parties, or used for advertising.
  • The channel's own statistics are kept while the authorization is active. The tool checks the authorization at least every 30 days and deletes this data if it has been revoked.

6. Revoking access and requesting data deletion

Access can be revoked at any time via the Google Account security settings. After revocation, local tokens stop working and are deleted.

To request deletion of your data, use the contact in section 8. Requests are handled within 7 days.

7. Cookies

This site does not use cookies or tracking tools.

8. Changes and contact

This policy may be updated; the date at the top indicates the current version. Questions, complaints and deletion requests can be sent by opening an issue in this repository.
